# Frontend

本地 React + Vite 工作台，当前展示客户池、证据详情和开发信人工审核流程。

## 本地运行

```bash
npm install
npm run dev
```

页面启动后会先读取 `/api/tasks` 和 `/api/tasks/{id}/leads`。真实数据存在时优先展示持久化客户档案；数据库为空或 API 不可用时会明确显示状态，并保留带标识的演示数据，不把演示数据伪装成生产数据。

## 设计系统

- 深色导航轨 + 白色工作区，青蓝色作为操作和证据强调色
- 客户列表采用表格行而非重复卡片，右侧使用证据检查面板
- 状态变化使用短时过渡、选中行高亮和审核反馈 Toast
- 支持 900px 和 600px 两档响应式布局，并尊重 `prefers-reduced-motion`
