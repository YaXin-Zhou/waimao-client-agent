# 外贸客户智能体｜本地版

## 启动

双击 `WaimaoClientAgentDesktop.exe`。程序会自动启动本地 API 和前端，并打开工作台页面。
如果默认端口被占用，程序会自动寻找附近的空闲端口。

## 首次配置

首次启动会在 EXE 同目录自动创建 `config/.env`。打开该文件，填写：

- `DEEPSEEK_API_KEY`：用于资料整理、核验和邮件生成；
- `TAVILY_API_KEY`：用于原有爬虫失败时的备用搜索；
- `ALI_IMAP_USERNAME` / `ALI_IMAP_PASSWORD`：读取收件箱；
- `ALI_SMTP_USERNAME` / `ALI_SMTP_PASSWORD`：发送已审核邮件。

保存后重新双击 EXE。密钥只保存在本机，不要发给他人或提交到 Git。

如果浏览器可以上网，但搜索提示“搜索服务暂时无法连接”，通常是新电脑的代理没有被 Python 请求继承。请在 `.env` 中把 `HTTP_PROXY` 和 `HTTPS_PROXY` 填成 FlClash 的实际 HTTP 代理地址，例如 `http://127.0.0.1:7890`（端口以 FlClash 页面显示为准），保存后重新启动程序。

## 日常操作

1. 在“找客户”填写产品、关键词、目标国家和行业。
2. 点击“搜索可发送客户”。系统按配置的搜索链路读取公开结果；遇到浏览器验证时会打开可见窗口等待人工完成。
3. 系统抓取官网、公开邮箱和业务证据，并自动筛选目标国家客户。
4. 在客户池查看合格客户，生成邮件后人工审核，再发送。
5. 在“本地数据库”查看全部资料，点击“导出 Excel”保存表格。

## 数据位置

- 客户数据库：`data/runtime/acquisition.db`
- Excel 文件：`data/exports/`
- 配置文件：`config/.env`

本交付包使用独立数据库，不会修改开发目录中的数据库。

## 重要边界

搜索平台可能临时限流或要求验证码。程序不会绕过验证码，也不会伪造客户资料；此时请在可见窗口完成验证，或稍后重试。
