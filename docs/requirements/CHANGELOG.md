# 需求与范围变更记录

本文件记录已经确认的范围调整。没有验收标准的内容不得标记为完成。

## 2026-09-09 · 收口而非扩展

| 项目 | 结论 |
|---|---|
| 提出方 | 项目负责人 |
| 目的 | 在域名和邮箱审核期间稳定现有核心流程 |
| 本轮范围 | 事实边界、状态一致性、异常可追踪性、文档和验收基线 |
| 明确不做 | 新业务功能、批量发送、真实邮箱联调、翻译功能扩展 |
| 代码调整 | 未知状态安全显示；移除虚构操作人；移除无后端支持的静态分页入口 |
| 验收重点 | 空任务、API 失败、任务切换、背调失败/重试、草稿未生成时不显示虚构内容 |
| 遗留条件 | 域名审核完成后，再做真实 IMAP/SMTP 连接和专用测试邮箱验收 |

## 变更准入规则

任何新增需求必须先补充：业务目的、影响模块、状态机影响、验收标准和是否进入当前阶段。当前阶段只允许修复缺陷、补齐既定交付和完善证据。
