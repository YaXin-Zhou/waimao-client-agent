# 核心领域切片验收记录

## 范围

本切片实现获客任务配置、潜客档案清洗和可配置客户评分，不接入搜索、AI、数据库或阿里邮箱。

## 已实现行为

- 目标产品、关键词、国家、行业、客户类型、语言和每日上限均由任务配置传入；产品主词、市场和客户类型可以留空，至少配置一个业务目录词或搜索关键词即可运行。
- 官网被规范为主域名，邮箱被规范为小写地址。
- 同一域名的多条搜索结果合并为一个客户档案。
- 多个公开邮箱去重后保留。
- 缺失官网、无效邮箱和冲突国家标记为待人工审核。
- 评分权重和实际信号由调用方传入，领域层不写死行业规则。
- 任务只允许沿定义好的状态机迁移。

## 虚构样例验收

样例包含两条 Northwind Outdoor 重复记录、一条完整的 Alpine Camp Supply 记录和一条无效目录记录。

预期结果：4 条原始记录清洗为 3 条档案；Northwind 合并为 1 条并保留 2 个邮箱；无效目录标记 `needs_review`；配置评分信号生成 A 级客户。
