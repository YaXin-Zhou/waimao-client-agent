# 浏览器自动导入助手

## 用途

这是本地部署的浏览器扩展。安装一次后，客户打开符合当前任务条件的 Google 或 Bing 搜索结果，
扩展会自动读取当前页面可见的官网链接，并提交给本地 API。之后仍由原系统负责官网抓取、
邮箱清洗、国家和行业核验、去重及数据库保存。

## 客户操作

1. 启动本地客户工作台和 API。
2. 正常点击客户工作台的“搜索可发送客户”。
3. 如果普通爬虫和自动浏览器失败，或本次搜索没有找到合格客户，插件会自动打开一次匹配条件的 Google 搜索页，并自动导入当前页面。
4. 回到客户工作台查看整理后的客户。

如果自动导入没有触发，也可以打开目标搜索结果页，点击浏览器工具栏中的“NORTHSTAR 客户导入助手”，再点击“导入当前搜索结果”手动重试。

不需要复制 JSON，也不需要填写公司名称或邮箱。扩展只读取当前页面，不自动刷新、不点击广告、
不绕过验证码，也不会发送邮件。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择项目中的 `browser_assistant` 文件夹。
5. 将扩展固定到工具栏。

这是一次性安装；交付 EXE 时需将该文件夹与安装说明一起交付。扩展只允许读取指定搜索结果页，并调用本机
`127.0.0.1:8002`，不会把客户资料发送到第三方服务。

## 边界

- 扩展使用当前浏览器正常会话，但不能绕过搜索平台的验证码或异常流量限制。
- 扩展只在搜索词同时包含当前任务的目标国家和产品/关键词/行业时自动导入，避免干扰其他搜索。
- 每个任务和搜索页面只自动导入一次；重复结果由本地数据库继续按官网域名去重。
- 插件每 30 秒检查一次本地搜索任务状态；只在发现新的失败任务或“合格客户为 0”的新任务时打开一次可见的浏览器页面，客户不需要自己判断何时使用备用方案。
- 搜索结果只是候选来源；官网、公开邮箱、国家和业务证据仍由本地核验流程确认。
- 当前版本按官网域名去重，最多读取当前页面 50 个官网候选。
